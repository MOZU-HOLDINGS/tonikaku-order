# 兎に角 - 卓上QR＆店舗自由印字システム (TM-m30Ⅱ対応)

店舗内に専用サーバーや常時起動PCを置かず、VPNや店舗ルーターの変更も一切行わずに、**GitHub Pages（無料ホスティング）** と **エプソン公式アプリ（Epson TM Print Assistant）** を連携させて、キッチンプリンター（EPSON TM-m30Ⅱ）から卓上QRや自由な伝票を印刷するシステムです。

---

## 🌟 特徴とメリット

1. **Diniiの注文業務を絶対に邪魔しない設計**
   - 印刷命令を送る瞬間（数十ミリ秒）だけプリンターと通信し、即座に切断します。
   - Diniiが注文伝票を出力している最中にボタンを押しても、エプソン公式アプリが安全にビジーを検知し、Diniiの通信を遮断・破壊しません。
   - 厨房の静穏を守るため、ブザー音は一切鳴らしません。
2. **導入・運用コスト 0円**
   - 店舗内サーバー不要、PC不要、月額費用不要。
   - GitHub Pagesで静的Webアプリとして完全無料稼働します。
3. **iPad・Android両対応**
   - 店舗にあるiPadやAndroidハンディ端末のブラウザからワンタップで即時印刷。
4. **「好きなものを印刷」できるフリー印字機能**
   - 卓番ごとのモバイルオーダーQRだけでなく、店内Wi-Fi案内、LINE公式アカウント友だち追加、Google口コミ用QR、厨房への業務連絡メモなども自由に印刷できます。

---

## 🚀 導入手順（3ステップ）

### ステップ1: GitHub Pages でWebアプリを公開する

1. GitHubに新しいリポジトリ（例: `tonikaku-printer`）を作成します。
2. 本フォルダ内の全ファイル（`index.html`, `css/`, `js/`, `README.md`）をコミット＆プッシュします。
3. GitHubリポジトリの **[Settings]** タブを開きます。
4. 左メニューの **[Pages]** をクリックします。
5. **Build and deployment** の Source で **「Deploy from a branch」** を選択し、Branch を `main` / `/(root)` に設定して **[Save]** をクリックします。
6. 数十秒〜1分ほどで公開URLが発行されます（例: `https://<あなたのGitHubユーザー名>.github.io/tonikaku-printer/`）。

---

### ステップ2: 店舗端末（iPad / Android）に公式アプリを入れる（初回のみ1分）

1. 店舗で使用する iPad または Android ハンディ端末を開きます。
2. **App Store** または **Google Play** から **「Epson TM Print Assistant」**（無料）を検索してインストールします。
3. アプリを起動し、初期設定を行います：
   - **プリンターの追加** をタップ。
   - 機種で **「TM-m30II」**（または自動検出されたプリンター）を選択。
   - インターフェースで **「TCP/IP (有線LAN / Wi-Fi)」** を選び、プリンターのIPアドレス（例: `192.168.1.xxx`）を入力。
   - **「テスト印刷」** を押してレシートが出力されることを確認。

---

### ステップ3: 店舗端末のホーム画面に追加する

1. iPadの **Safari** または Androidの **Chrome** で、ステップ1で発行されたGitHub PagesのURLを開きます。
2. ブラウザのメニューから **「ホーム画面に追加」** を選択します。
3. これで、ホーム画面に専用アプリアイコンが配置され、ワンタップでフルスクリーン起動できるようになります。

---

## 📱 日常の使い方

### 1. 卓上QRコードの即時発行
* ホーム画面のアイコンからアプリを開きます。
* 案内する **卓番ボタン（例:「卓 5」）** をタップするだけで、1秒以内にTM-m30Ⅱからモバイルオーダー用QRレシートが発行・カットされます。

### 2. フリー印字（好きなものを印刷）
* 画面上部の **「✏️ フリー印字」** タブをタップします。
* タイトル、本文、QRコードにしたいURL（またはテキスト）を入力します。
* 「📶 店内Wi-Fi案内」「💬 LINE友だち追加」「⭐ Google口コミ」「📝 厨房メモ」などの定型文ボタンを押すと、ワンタップで入力欄が埋まります。
* **「🖨️ この内容で印刷する」** をタップすると、そのままプリンターから出力されます。

### 3. レシートの事前確認
* **「👁️ レシート確認」** タブをタップすると、印刷される伝票のイメージ（卓番、文言、QR配置）を画面上でリアルタイムに確認できます。

### 4. 店舗情報・卓番のカスタマイズ（設定メニュー）
* 画面右上の **「⚙️（設定ボタン）」** をタップします。
* 以下の項目を自由に編集でき、設定内容は端末のブラウザ（localStorage）に自動保存されます：
  - **店舗名**（レシートの最上部に印字される名前）
  - **モバイルオーダーのベースURL**（卓番が末尾に付与される基本URL）
  - **卓番リスト**（「1, 2, 3, カウンター1, テラスA」など自由に名称を設定可能）
  - **用紙幅**（80mm / 58mm 切り替え）
  - **QRコード印字サイズ**（大・中・小）
  - **ヘッダー・フッターの注釈文言**

## 🛡️ Diniiとの共存・安全性について

キッチンプリンターはDiniiの基幹業務を担っているため、本システムは以下の安全策を徹底しています。

1. **長時間の接続占有を禁止**
   - 通信は「URLスキーム呼び出し → エプソン公式ドライバーがパケット送信 → 即座にソケット切断」という流れで数ミリ秒で完了します。
2. **Dinii印刷中の衝突回避**
   - Diniiが注文伝票を印刷している瞬間に本アプリから印刷を実行した場合、プリンターのTCPポート9100はビジー応答を返します。Epson TM Print Assistantはこれを検知して安全に待機またはエラーダイアログを表示するため、Diniiの通信ソケットを破壊しません。
3. **厨房の誤認防止**
   - 出力される伝票の上部に `【卓上用QR】` と明記されるため、厨房スタッフが調理指示伝票と見間違えるリスクを防ぎます。
   - 注文伝票用のブザー音は鳴らない設定になっています。
